# CHEM 1010 --- Introductory Chemistry

Course materials, teaching notes, and instructional resources for CHEM
1010 --- Introductory Chemistry.

This repository serves as a working archive for course development,
instructor planning, and instructional materials maintained outside of
Canvas. Canvas remains the primary course-delivery platform for
students.

## Start Here

Use the documentation at the level appropriate to the question you are
trying to answer:

    instructional framework: course design, learning cycle, recurring
    activities, role of face-to-face instruction, assessment
    architecture, and guidance for using this repository with an LLM.
-   **[Fall 2026 Lecture & Study
    Guide](docs/CHEM-1010-Fall-2026-Lecture-Study-Guide.md)** ---

    conceptual and instructional map for Unit 1, including how Sections

## Documentation Hierarchy

The repository is intended to answer increasingly specific questions:

``` text
README.md
    What is in this repository and where should I start?
        ↓
COURSE-GUIDE.md
    How is CHEM 1010 designed to work?
        ↓
Semester guide
    What happens when this semester?
        ↓
Unit README
    What is this unit trying to accomplish?
        ↓
Section roadmap
    How should this section be understood and taught?
```

Current Canvas materials, the syllabus, institutional requirements, and
other authoritative course sources take precedence over these
reconstructed documentation files when they conflict.
